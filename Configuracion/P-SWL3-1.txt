! =====================================================
! ACL 
! =====================================================
ip access-list extended ACL_BACKOFFICE
 permit udp any any eq 67
 permit udp any any eq 68
 deny ip 172.16.3.192 0.0.0.31 172.16.3.0 0.0.0.63
 deny ip 172.16.3.192 0.0.0.31 172.16.4.48 0.0.0.15

exit

 permit udp any any eq 67
 permit udp any any eq 68
 deny ip 172.16.3.0 0.0.0.63 172.16.3.192 0.0.0.31
 deny ip 172.16.3.0 0.0.0.63 172.16.4.48 0.0.0.15
 permit ip 172.16.3.0 0.0.0.63 any
exit

ip access-list extended ACL_SOPORTE_TI
 permit udp any any eq 67
 permit udp any any eq 68
