1. Configuración de Red y Salida a Internet
A. Configurar Netplan (IP Pública)
Comando para editar: sudo nano /etc/netplan/01-network-manager-all.yaml

YAML
network:
  version: 2
  renderer: networkd
  ethernets:
    ens3:
      dhcp4: no
      addresses:
        - 17.6.0.38/30
      routes:
        - to: 0.0.0.0/0
          via: 17.6.0.37
      nameservers:
        addresses:
          - 8.8.8.8
          - 1.1.1.1
(Nota: Asegúrate de que tu interfaz se llame ens3 o eth0, cámbialo según corresponda en tu nodo).
Comando para aplicar: sudo netplan apply

B. Forzar DNS para poder descargar Apache
Comandos directos en la terminal:

Bash
sudo rm -f /etc/resolv.conf
echo "nameserver 8.8.8.8" | sudo tee /etc/resolv.conf
ping -c 2 google.com
(Espera a que el ping te responda exitosamente antes de continuar).

2. Instalación del Servidor Web (Apache2)
Comandos directos en la terminal para actualizar e instalar el motor web:

Bash
sudo apt update
sudo apt install apache2 -y

4. Cargar la Imagen del Diseño
Para que la página web muestre el logo correctamente, debes colocar la imagen en la carpeta pública de Apache.

Renombra la imagen en tu computadora a arbol.jpg.

Súbela al contenedor del Servidor Web en PNETLab.

Asegúrate de moverla a la ruta exacta usando este comando:


sudo mv arbol.jpg /var/www/html/arbol.jpg
Dale los permisos de lectura para que cualquiera que entre a la web la pueda ver:

Bash
sudo chmod 644 /var/www/html/arbol.jpg
echo "17.6.0.38 www.CaribeComms-ServiceQuisqueya.com.do" | sudo tee -a /etc/hosts
